# PCB Design Projects

Welcome to my **PCB Design Projects Repository**.

This repository contains my PCB design projects created while learning and working in the field of **Electronics and Communication Engineering (ECE)**.

## 📌 About This Repository

Here, I upload my different PCB design projects. Each project contains design files and other related resources such as:

* 📐 Schematic Design
* 🔲 PCB Layout
* 🧩 KiCad Project Files
* ⚙️ Gerber Files
* 🖼️ PCB Images
* 🔄 3D PCB Views
* 📄 Project Documentation

## 🛠️ Software Used

The PCB designs in this repository are primarily created using:

* KiCad
* Other Electronic Design Automation (EDA) tools when required
